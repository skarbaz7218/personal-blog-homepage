# Personal Blog Homepage

A responsive personal blog homepage built using HTML, CSS, and JavaScript.

## Features

- Responsive blog homepage design
- Blog post cards with images, titles, descriptions, and dates
- Category filtering (Tech, Travel, Food)
- Pagination to display a limited number of posts per page
- Search posts by title (Bonus Feature)
- Mobile-friendly layout
- Smooth hover effects and modern card styling

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
personal-blog-homepage/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
